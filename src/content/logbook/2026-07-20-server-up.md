`mukto.net` has been answering SSH since 14:20 today. Four accounts so far, for the people setting it up, so we find the problems first.

What's running:

- Debian stable, unattended security upgrades, nothing exotic
- `~/public_html` served by nginx at `mukto.net/~you`
- IRC on `irc.mukto.net`, channel `#adda`
- Forgejo at `git.mukto.net`, accounts tied to your shell account

What isn't: mail, databases, anything that needs a second server. Quotas are 2 GB of disk and 30 processes per user while we see how people actually use it.

Backups run nightly to a second machine across town, encrypted before they leave. I restored one on purpose on Saturday to check it works. It does.

The first invites for the founding cohort go out next week, in the order people signed up at the founding adda. If something breaks, say so in `#ops`. If it's 3am, say so anyway and I'll read it at 9.
